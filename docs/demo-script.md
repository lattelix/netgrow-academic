## Дополнительно (если остаётся время)

- `/calendar` — показать общесменные и командные события.
- `/admin` (под аккаунтом администратора) — управление сменами, справочником компетенций,
  ролями пользователей.
- Печать сводки по проекту (кнопка «Печать сводки» на карточке проекта).
- Показать запрещённое действие: под участником открыть `/admin` напрямую — система
  покажет состояние «Доступ запрещён» вместо содержимого раздела.

## Восстановление после сбоя

Если во время демонстрации данные оказались в неожиданном состоянии (например, случайно
одобрена не та заявка), достаточно выполнить в отдельном терминале:

```bash
pnpm db:reset
```

и обновить страницу браузера (`F5`) — состояние данных полностью и детерминированно
пересоздаётся заново, сессия входа при этом сохраняется (cookie не сбрасывается), но
рекомендуется также нажать «Сменить аккаунт» и войти заново, чтобы гарантированно увидеть
свежие данные текущего пользователя.

Если сервер завис или порт занят:

```bash
# в терминале с запущенным `pnpm dev`
Ctrl+C
pnpm dev
```

Полная переустановка окружения (крайний случай):

```bash
rm -rf node_modules data/netgrow.db
pnpm install
pnpm db:reset
pnpm dev
```
